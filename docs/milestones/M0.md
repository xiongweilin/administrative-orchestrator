# M0 — semantic foundation

## Goal

Turn the empty repository into an executable administrative-domain semantic core that can accept an onboarding request, evaluate a deterministic policy, require an explicit current decision, and preserve the boundary between decision, execution authorization, effect, verification, and reopen.

M0 does **not** perform external writes.

## Delivered

- product/repository boundary;
- canonical `AdministrativeCase` lifecycle;
- Principal / RoleAssignment / Delegation primitives;
- versioned policy references and evaluations;
- onboarding policy evaluator;
- Decision and exact-scope ExecutionAuthorization records;
- two-axis effect risk classification;
- effect/evidence/realization/outcome records;
- guarded case transitions;
- explicit reopen transition;
- FastAPI onboarding ingress/read/decision surface;
- semantic regression tests;
- CI for lint and tests.

## Acceptance

M0 is complete when all of the following are true:

1. repository installs on Python 3.12 with the declared development dependencies;
2. `ruff check .` is green;
3. `pytest -q` is green;
4. `/healthz` and `/readyz` can start without external infrastructure;
5. a complete onboarding request reaches `awaiting_decision`;
6. an incomplete onboarding request reaches `gathering_facts`, not `reopen_required`;
7. approval is bound to the exact current case version and policy version;
8. an execution authorization cannot be minted from a stale or non-approve decision;
9. a planned effect cannot exceed the authorization operation scope;
10. a case cannot exit `reopen_required` without explicit reopen.

## Explicitly deferred to M1+

- PostgreSQL persistence / Alembic;
- DBOS durable workflows;
- append-only audit/event journal;
- `agent-kernel` compatibility pin and runtime integration;
- organization directory persistence;
- policy persistence/compiler;
- Feishu multi-user ingress;
- Odoo/Keycloak adapters;
- actual effect dispatch;
- external read-back/reconciliation;
- administrative operations console.

Deferral is deliberate: those layers must consume the M0 semantic distinctions instead of silently redefining them.
